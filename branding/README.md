# Varsayılan logolar

Bu klasöre konan PNG / SVG / JPG / WebP dosyaları, Master Data → Kurumsal görünüm ekranında logo yüklenmemişse
giriş ekranında, sol menüde ve arka plan filigranında varsayılan olarak gösterilir. Dosyalar ada göre sıralanır
(ör. `01-otokar.svg`, `02-otokar-savunma.svg`). Yalnızca kurumun resmi logo dosyalarını kullanın.
